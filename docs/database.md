# Database

PostgreSQL through Prisma 7 (`backend/prisma/schema.prisma`, generated client in `backend/src/generated`, not committed). UUID ids, snake_case tables, `timestamptz` timestamps, `date` columns for calendar days. History is never cascaded away: foreign keys are RESTRICT, users are deactivated, records are never deleted.

## Main tables

| Table                                                    | Notes                                                                                                                                     |
| -------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| schools                                                  | Tenant. Timezone defaults to Africa/Accra.                                                                                                |
| users, teacher_profiles                                  | Email unique and lowercase (CHECK). Staff ID unique per school. Password hash is null until activation.                                   |
| sessions, auth_tokens, email_outbox                      | Hashed tokens only. One active invitation per user (partial unique index).                                                                |
| subjects                                                 | National catalogue (school_id null) plus school-defined language subjects pointing to the Ghanaian Language framework.                    |
| academic_years, terms, term_weeks, school_classes        | One current term per school (partial unique index).                                                                                       |
| teaching_assignments                                     | Teacher, subject, class, term. Unique per class, subject and term. `paced_per_week` remembers the weekly count used at the last publish.  |
| timetable_entries                                        | Weekly slots. Exclusion constraints stop overlaps for a teacher or a class (weekday, time range, date range), ignoring soft-deleted rows. |
| lessons                                                  | Dated occurrences. Unique per assignment, date and start. `week_number` is the paced curriculum week.                                     |
| absences, school_calendar_days, week_policies            | Week policies: exactly one of level or class (CHECK), one policy per term, week and scope.                                                |
| curriculum_schemes, curriculum_weeks, curriculum_entries | Versioned per term, one published per term (partial unique index). Entries are unique per scheme by a natural-key hash.                   |
| import_batches, import_rows                              | Unique per school, term and file checksum (idempotent upload).                                                                            |
| teaching_records, teaching_record_topics                 | Exactly one record per lesson. Draft or submitted.                                                                                        |
| notifications                                            | Unique per recipient, type and record.                                                                                                    |
| audit_logs                                               | Append-only, enforced by a trigger.                                                                                                       |

## Migrations

- `*_init`: generated by Prisma.
- `*_constraints`: hand-written. Covers the extensions (btree_gist, pg_trgm), partial unique indexes, exclusion constraints, CHECKs, trigram indexes for name search and the audit trigger.

Create a new migration with `pnpm --filter @school/api exec prisma migrate dev --name <name>` (development only). Apply migrations with `pnpm db:deploy`. Before committing, check that a generated migration does not drop any of the hand-written objects.
